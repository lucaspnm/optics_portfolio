# Optics Portfolio
# Author: Lucas Sanchez

A collection of small optics simulations and design studies focused on Fourier optics, relay systems, adaptive optics, fiber coupling, polarization, and optical hardware concepts relevant to quantum/laser systems.

## Projects

1. Fourier Optics and 4F Relay Simulation
2. Pupil Function, PSF, and Aberration Modeling
3. Idealized SLM Phase Correction
4. Future: Gaussian Beam and Fiber Coupling Calculator
5. Future: Zemax/OpticStudio COTS Relay Design

## Motivation

This repository is intended to rebuild and demonstrate practical optical engineering fundamentals through simulation, whiteboard-style explanations, and eventually optical design examples.
